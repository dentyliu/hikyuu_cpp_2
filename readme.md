# 项目一：基于Hikyuu的经典均线策略回测系统
## 项目定位：熟悉Hikyuu数据接口、回测引擎、C++量化基础编码，建立框架使用能力
## 核心技术点：C++面向对象封装、Hikyuu K线数据读取、均线指标计算、策略逻辑编写、回测绩效统计、结果可视化导出
## 项目功能清单
### 1.数据模块：基于Hikyuu接口读取A股日K/60分钟K线数据，实现数据清洗（缺失值、异常值剔除）
### 2.策略模块：实现双均线策略（5日线+20日线）、金叉买入、死叉卖出核心逻辑
### 3.回测模块：自定义初始资金、仓位比例、手续费、滑点参数，适配实盘规则
### 4.绩效模块：自动计算收益率、最大回撤、夏普比率、胜率、盈亏比核心量化指标
### 5.输出模块：回测日志本地存储、绩效报表TXT导出、K线策略信号标记输出
## 亮点：手动封装指标计算逻辑（不调用现成API）、优化数据读取效率，对比原生Hikyuu接口性能差异
