# 项目定位：覆盖因子挖掘、选股模型、风险控制
## 核心技术点：C++容器高效遍历、多因子加权打分、行业中性化处理、仓位风控、批量回测、参数寻优
## 项目功能清单
### 1.因子构建：基于Hikyuu行情数据，实现3类核心因子（动量因子、价值因子、波动率因子）C++原生计算
### 2.选股逻辑：多因子加权打分，剔除ST股、次新股，按月调仓批量选股
### 3.风控模块：最大单票仓位限制、行业分散风控、回撤阈值止损机制
### 4.参数寻优：遍历不同因子权重、调仓周期，筛选最优策略组合
### 5.数据存储：将因子数据、选股结果写入MySQL，实现数据持久化
## 亮点：解决因子共线性问题、实现风控兜底逻辑、对比单因子与多因子回测收益差异，体现量化思维
